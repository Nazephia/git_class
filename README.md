# Grades report

Small C++ program that reads a file of students and their grades
(scale 0–20, passing grade 10) and prints a report.

## Build

```bash
make
```

## Run

```bash
./grades grades.txt
```

## Input format

One student per line: the name followed by their grades, separated by spaces.

```
Andrea 15 12 18
Carlos 8 11 12
```
